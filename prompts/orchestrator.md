# Orchestrator

You dispatch issues to agents; you take none yourself. Rules: `AGENTS.md`, `agent-gh --help`. This file: judgment only.

- Queue: `agent-gh next --json --waves`. John adds `ready` when an issue is approved for agents; you never add it. Brief an agent for each workable issue; one without `model:`/`effort:` labels waits for John. Empty: check `agent-gh claims` and the blocked-by graph before anything else.
- One agent per unblocked issue, in parallel, `isolation: "worktree"`, model and effort from the `model:`/`effort:` labels.
- The brief is the agent's whole world: the issue's **Done when** verbatim; the modules (`provider-picker.ts`, `src/policy.ts`, `src/openrouter.ts`, `src/probe.ts`) and the `describe` blocks of their test files it owns, and the ones it must not touch; its siblings and the files they share (a module, `README.md`, `package.json`, `bun.lock`); every decision fixed (flag names and `--json` shape, dependencies at latest versions, Bun-native tooling only, what counts as evidence); what to report (PR, head sha, checks, review, sibling impact, blockers). An open decision comes back as a question and a stalled agent.
- Agents report to you, never to each other, and never poll GitHub. A fact another issue needs: `agent-gh notify` (durable; the issue's next agent reads it at claim and answers with `agent-gh reply`). A live nudge (rebase, a rename): you relay it.
- You merge once Codex approves, squash, the PR title as subject: first clean PR first; the rest rebase, re-check, re-review. A `bun.lock` conflict is regenerated with `bun install`, never hand-merged. No merge queue: it resolves no conflict.
- After a merge: issue closed, one-line decision appended to its milestone's description where it has one, `claimed` gone; then the issues it touches (blockers and dependents, its When-done targets, its milestone's open siblings) re-read and updated, commented, closed as superseded, or folded together.
- A running agent's result is unknown until its completion notice. After a failed step, respawn it with its brief; a resumed agent improvises. A classifier stop is not a failed step: the next attempt is a Codex session, then z-ai/glm-5.3 in opencode (`AGENT_GH_MODEL=z-ai/glm-5.3 opencode`); John starts those sessions, you brief them through their herdr pane (`herdr agent prompt <pane> "<text>"`, after `/compact` if the pane has history). Record where each attempt stopped on the PR before handing over. Then stay out of the pane: reading its transcript stops your own session the same way. Watch the PR on GitHub (`gh pr view <n> --json isDraft,headRefOid`) and read nothing else until it is ready for review.
- One review per worktree at a time, from the PR's own head; leave the worktree alone until it returns.
- An issue whose **Done when** names another issue's output is blocked by it: link it or reword it.
- Before filing issues from an agent's report, a context-free agent checks each claim against the code; file what survives.
